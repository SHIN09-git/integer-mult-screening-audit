# 2026-10-22 本机重新计时证据

这些文件来自公开整理阶段一次完成的 `python -I -S -B reproduce.py --mode benchmark` 运行。环境为 Windows 11 / CPython 3.12.14，耗时约 209 秒。运行在复制的研究包上进行，未覆盖原研究目录。

- `TIMINGS.json`：350 个初始进程样本。
- `PAIRED-TIMINGS.json`：168 个相邻配对进程样本。
- `COMPETITIVE-TIMINGS.json`：63 个较高目标比较进程样本。
- `new-timing-summary.json`：上述新样本的独立重算摘要。
- `historical-timing-summary.json`：对保留的 581 个历史样本重算的摘要。
- `validation.json`：精确核验、来源核验及两套计时核查的机器记录。
- `logs/`：三个精确核验日志与三个新计时日志。

解释器路径在复现入口内移除；三个计时日志中的本地输出目录在公开复制时替换为 `<output>`。除这些路径信息外，原始数值、结果、日志文本和机器记录均保留。

`validation.json` 中的清单数量 57 对应运行时已经冻结的核心文件。之后补齐公开文档，并将两项已修改文本规范为 LF 换行；最终字节由根目录清单固定。默认复现入口会再次检查当前全部清单，并重算这里保存的新计时摘要。

历史测量与这次重新计时不构成独立团队复现；没有将两个日期的样本混成一组统计。
